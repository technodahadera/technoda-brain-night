# בתוך הראש שלהם | ערב הורים וילדים בטכנודע

אתר בעברית לערב מחצית של תוכנית המחוננים. דף הבית מוביל למסך מנחה, להצטרפות משפחות ולתרגול עצמאי.

## הפעלה באודיטוריום

1. פתחו את האתר ב־Chrome במחשב שמחובר למקרן ולמערכת ההגברה. לחצו על ״מסך מנחה״ והמתינו להודעה ״מוכן לקבל משפחות״.
2. הקרינו את ה־QR או שתפו את קישור המשפחות דרך הכפתור במסך המנחה. מי שכבר פתח את דף הבית יכול להצטרף גם בעזרת קוד החדר.
3. הפעילו לפי הסדר את האתגר, ההצבעה, חשיפת התוצאות וההסבר המדעי. בתחנות שמע, הכפתור משמיע את הקטע ומעבר להצבעה מתבצע בתום ההשמעה. אפשר לפתוח הצבעה ידנית. בתחנות חזותיות המנחה קובע מתי עוברים להצבעה, גם אחרי שהטיימר הגיע לאפס.
4. השאירו את מסך המנחה פתוח במשך האירוע. רענון שלו פותח חדר חדש. ״מצב תרגול״ מאפשר להזין הצבעות לדוגמה במסך המנחה ולראות גרף. מדד זמן ההצבעה בתחנה 6 מתחיל בפתיחת השאלה ומסתיים כשהקול מתקבל במחשב המנחה, וכולל את השהיית החיבור.

האתר הסטטי מתפרסם ב־GitHub Pages. הצבעות אנונימיות עוברות ישירות בין הדפדפנים ב־WebRTC. שרת ה־PeerJS הציבורי משמש להקמת החיבור. ההצבעות נשמרות בזיכרון של מסך המנחה למשך התחנה. לפני הערב, מומלץ לבצע סריקה והצבעת ניסיון ממכשיר אמיתי על רשת האולם ולבדוק את עוצמת השמע.

## עריכה

- `data.js` מחזיק את התוכן, אפשרויות המענה והמקורות המדעיים.
- `media.js` מחזיק את המנגינות ואת שרטוט הקוביות. `tools/kitchen-audio.py` מייצר את קטע אפקטי המטבח.
- עיצוב ופריסה נמצאים ב־`style.css`. לפיתוח מקומי הריצו `python -m http.server 8000` משורש המאגר ופתחו את `http://localhost:8000`.

## קרדיטים

- הלוגו מאתר [טכנודע](https://www.technoda.org.il/).
- תצלום איילין קולינס מ־NASA באמצעות [scikit-image](https://scikit-image.org/docs/stable/api/skimage.data.html#skimage.data.astronaut). תמונת הכתמים היא עיבוד של התצלום.
- איור הפתיחה נוצר עבור האתר ב־ImageGen לפי בריף של מוח ורוד תלת־ממדי, קוביות וברק על רקע סגול.
- רישיונות Rubik, PeerJS ו־QRCode Generator מצורפים בתיקיית `assets`.
